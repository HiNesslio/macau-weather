# 實時天氣與城市環境整合

沿用既有頁面。首屏主角是澳門實況，天氣來源是 SMG 觀測描述；今日預報不驅動當下動畫。移除 18 種場景選擇、演示輪播、手動日夜和 URL 覆寫。只保留暫停動畫控制。資料未取得時使用中性背景和明確載入／失敗文字。

四層雲使用使用者 Desktop/weather 提供的 WebP，速度 5 / 11 / 22 / 42 px/s，依教程的透明度、位置和天氣參數平鋪；尺寸變更才重建預縮放貼圖，背景分頁及不在視窗時暫停，尊重減少動態效果。更新天氣時緩動調整雲層，日夜採 Open-Meteo 日出日落與澳門天文位置備援，每分鐘重算。

空氣面板顯示 PM2.5 及具名站點；六站濃度表與 AQI 預報分開。官方 AQI 預報保留有效日期及地區。UV 標示讀數時間，完整氣象站表標示氣溫、濕度、風、海平面氣壓及露點。各來源失敗不覆寫成零，超時或過期有提示。

驗收：真實 API 正常／部分失敗／無資料；場景不受 URL 影響；實況變化自動換景；日出日落、跨日、減少動態效果；桌面及手機無頁面橫向溢出，資料表可獨立橫向捲動。局部介面改造採自檢，不做風格探索或獨立評分。
