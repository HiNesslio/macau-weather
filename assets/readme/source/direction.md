# README 視覺方向

模式：完整 README 整理，繁體中文；使用者明確要求 GIF。

對象：想即時查看澳門天氣的使用者，以及想部署或了解資料來源的開發者。
一句話價值：即時實況、官方警告和逐小時預報，放在同一頁。
主要證據：目前網站的實際截圖，以及正式 API 的可驗證資料。
第一個動作：開啟正式網站。
視覺主題：沿用網站的夜間藍色天空、雲層和清楚數值；GIF 以聚焦實況、警告與即時詳情的順序介紹用途，不捏造生效警告。

Palette：#0b192a / #f4f9ff / #9fc9e4 / #f1d4a3 / #91a8bb。
Typography：系統無襯線，標題 54、內文 24；主要說明同時保留在 README Markdown。
Shape：24px 圓角，1px 細線，8px 基準間距。
Motif：真實天氣頁和數據區域的短距離聚焦。
Composition：背景證據與低密度標題整合。

GIF 使用 SVG 版面與實際頁面截圖製作；不使用生成圖片。SVG 保留為可編輯來源，另輸出 PNG 靜態備援，README 嵌入 GIF。GIF 的資料是錄製當刻的畫面，並非讀者當下的即時天氣。

當日高低溫顯示預測值，來自 c_7daysforecast.xml；截圖須使用修正後介面。
